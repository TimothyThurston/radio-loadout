# Contributing to Radio Loadout

Reproducible bug reports and research on radios, programming formats, field
limits, and compatibility are welcome. Include the radio, programming application
and version, expected and actual behavior, and privacy-safe reproduction steps.
Do not submit sensitive channel data or material you lack permission to share.

source. The license permits its defined noncommercial uses but does not authorize
modification, derivative works, or redistribution. Before preparing or submitting
code patches, tests, documentation patches, or other changes to project material,
contact Timothy Thurston through the repository to agree on a separate permission
arrangement. An issue discussion or patch submission alone is not such an agreement.
The arrangement must cover the proposed work and the permissions needed to use
and license the contribution; no automatic contributor rights transfer is asserted.
